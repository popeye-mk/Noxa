## history/

The project's design documents from the original build (then called
"Guardian"): the full phased plan, per-phase specs with device checkpoints,
and setup notes. Kept as the record of how Noxa was designed and proven —
each phase was validated on real hardware before the next began. Not
maintained; the app has moved past them.
